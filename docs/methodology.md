# Methodology

## Scope

This lab simulates an internal penetration test focused on Active Directory compromise, lateral movement and pivoting across segmented networks.

The assessment was performed in a controlled lab environment with intentionally vulnerable machines.

## Rules of Engagement

- No real systems were targeted.
- No public infrastructure was scanned.
- No real credentials are included.
- All IP addresses, usernames and sensitive evidence have been anonymized.

## Methodology Phases

1. Network discovery
2. Port and service enumeration
3. Initial access
4. Linux host enumeration
5. Pivoting to internal networks
6. Windows host discovery
7. Credential discovery and validation
8. Active Directory enumeration
9. Lateral movement
10. Domain Controller compromise
11. Reporting and mitigation planning

## Tools Used

- Nmap
- Dirsearch
- Chisel
- Proxychains
- CrackMapExec / NetExec
- xfreerdp
- PowerView
- Mimikatz
- Hashcat

## Key Skills Practiced

- Internal network enumeration
- Pivoting
- Credential attack simulation
- Windows and Linux enumeration
- Active Directory security assessment
- Lateral movement analysis
